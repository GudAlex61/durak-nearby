# Дурак рядом · 0.3.1

Flutter-приложение для Android и iOS: игра с ботом и с телефоном рядом по BLE,
без Wi-Fi и игрового сервера. Собственный игровой код — MIT.

## Играть

На главном экране выберите уровень бота и нажмите «Играть с ботом».
В «Настройках партии» доступны 24/36 карт и переводной режим. Эти же настройки
применяются при создании Bluetooth-стола. В колоде из 24 карт — 9, 10, валет,
дама, король и туз каждой масти; каждому игроку по-прежнему раздаётся 6 карт.

## Управление жестами

- Атака и подкидывание: потяните карту из руки вверх и положите на стол.
- Защита: положите свою карту прямо поверх нужной небитой карты.
- Перевод: положите карту того же достоинства в свободное место «Рядом».
- Взятие: нажмите «Взять»; также можно перетащить стопку вниз в свою руку.
- Завершение/бита: перетащите стопку вверх к сопернику, когда зона подсвечена.
- Прокрутка руки: ведите влево/вправо. Перетаскивание карты начинается вверх.

Для взятия есть кнопка «Взять». Остальные ходы — жестами. Неверный сброс возвращает карту в руку; устаревший жест
после обновления стола отклоняется. До окончания анимации ввод блокируется.
Для screen reader у стопки предусмотрены действия взятия и завершения.

Перевод запрещён после начала защиты, после «беру» и при недостаточной руке
принимающего. После «беру» соперник ещё может подкинуть и завершает розыгрыш.
Добирает сначала атакующий. Открытый козырь забирается последним.

## Бот и интерфейс

Три уровня: лёгкий выбирает случайный допустимый ход, обычный бережёт козыри,
сложный также выбирает порядок защиты и подкидывания. Чужую руку и порядок
колоды бот не использует. Пока приложение в фоне, бот стоит на паузе.
Статистика побед/поражений/ничьих доступна в рамках текущего запуска.

Анимации: раздача с переворотом карт, перелёт из руки на стол, защита,
сбор карт при «беру», уход в биту и добор. Траектории связаны с фактическими
позициями виджетов. Системное уменьшение движения отключает перелёты.
Системная кнопка Back и кнопка интерфейса запрашивают подтверждение выхода.

## Bluetooth

1. На двух телефонах установите одинаковую версию 0.3.1.
2. Включите Bluetooth и предоставьте разрешения.
3. Ведущий выбирает параметры партии и нажимает «Создать стол».
4. Гость нажимает «Найти стол рядом», вводит шестизначный код и выбирает стол.
5. При разрыве ведущий оставляет стол открытым, гость нажимает «Подключиться снова».

Оба приложения держите на переднем плане. Состояние после завершения процесса
не восстанавливается. Протокол 0.3.1 несовместим с 0.1.x: обновите оба телефона.
На Android 7–11 при поиске может требоваться включённая геолокация ОС.
Реальный радиообмен Android↔iPhone и iPhone↔iPhone ещё требует приёмки на телефонах.

## Android

Минимум Android 7 / API 24, target SDK 36. APK включает ARMv7, ARM64 и x86_64.
Сборка Release подписана тестовым ключом. Версию 0.1.1 можно обновить поверх;
перед установкой поверх 0.1.0 требуется удаление старого приложения, поскольку
тестовая подпись менялась. Для магазина используйте свой production-ключ.
Ключи в архив исходников не входят; детали — `docs/SIGNING.md`.

## iOS

Нативный проект iOS 13+ находится в `ios/Runner.xcworkspace`. На Mac с Flutter,
Xcode и CocoaPods выполните:

```sh
bash tool/ios_check.sh
```

Скрипт собирает приложение для iPhone Simulator, устанавливает его,
запускает интеграционный тест, делает скриншот и собирает неподписанный
arm64 IPA для устройства. Установка с Windows через AltStore — в `docs/IPHONE_INSTALL.md`. Для установки на настоящий iPhone выберите
свою Team в Xcode; для подписанного IPA — `flutter build ipa --release`.
Подробности — `docs/IOS.md`. iPhoneOS Release 0.3.1+5 успешно собран на macOS:
https://github.com/GudAlex61/durak-nearby/actions/runs/40641671235 .
Для установки готового неподписанного IPA используйте `docs/IPHONE_INSTALL.md`.

## Разработка и проверки

Инструменты: Flutter 3.35.7, Dart 3.9.2, JDK 17, Android SDK 36.

```sh
flutter pub get
flutter analyze
flutter test --reporter expanded
flutter build apk --release
flutter test integration_test/app_test.dart -d <device-id> --dart-define=TEST_MODE=true
python tool/android_ui_smoke.py --adb adb --serial emulator-5554 --output android-qa
```

В `.github/workflows/ios-delivery.yml` — проверка симулятора и Android APK.
Независимая iPhoneOS-сборка — `.github/workflows/iphone-device.yml`.
Фактическая сборка IPA, анализ и 67 тестов успешно выполнены на macOS.
Интеграционный сценарий игры с ботом прошёл на iPhone Simulator.

Фактические результаты и границы проверок — `docs/TEST_REPORT.md`, анимации —
`docs/ANIMATIONS.md`, лицензии — `THIRD_PARTY.md`.
