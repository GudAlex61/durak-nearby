# Тестовая подпись Android

APK 0.3.0 собирается в режиме Release, но подписан development-ключом.
В `android/app/build.gradle.kts` выбран стандартный debug signing config.
Для публикации настройте отдельный production signing config.

Ключ `DurakNearby-development.keystore` хранится отдельно от исходников.
Чтобы пересобрать APK с той же тестовой подписью, используйте его как
`~/.android/debug.keystore`. Стандартные параметры debug signing:
псевдоним `androiddebugkey`, пароль хранилища и ключа `android`.
Публичный отпечаток сертификата — в `docs/qa/apk-signature.txt`.

В архиве MIT-исходников ключа нет. Для обновления уже установленного приложения
нужна та же подпись; первая версия 0.1.0 использовала другой ключ, поэтому её
нужно удалить перед установкой 0.3.0. Сохранение партии между перезапусками
в этой версии не реализовано.
