# Дурак рядом: установка на iPhone с Windows

Это инструкция для нативного iOS-приложения. Для игры по Bluetooth нужны
реальные телефоны. Сборка для iPhone Simulator на телефон не устанавливается.

## 1. Получить IPA через облачный Mac

В исходниках 0.3.0 настроен GitHub Actions: он запускает тесты и собирает
**DurakNearby-ios-unsigned.ipa** на macOS. Для этого этапа Apple ID не нужен.

1. Создайте свой GitHub-репозиторий. Можно закрытый; macOS-раннер может расходовать
   квоту Actions вашего тарифа. Перед запуском проверьте Billing → Actions.
2. Распакуйте `DurakNearby-source.zip`. В корень репозитория загрузите **содержимое**
   каталога `durak_bt`, включая `.github`: рядом должны лежать `pubspec.yaml`,
   `lib`, `ios`, `test` и `.github`. Не загружайте один ZIP вместо исходников.
3. Откройте Actions → Mobile checks → Run workflow. Если GitHub попросит разрешить
   Actions для своего репозитория, включите их. Проверьте, что unit и ios зелёные.
4. В завершённом запуске откройте Artifacts → **DurakNearby-iOS**, скачайте архив
   на Windows и распакуйте его. Нужен файл **DurakNearby-ios-unsigned.ipa**,
   не `ios-simulator.zip` и не ZIP с `.app`.
5. Файл `ios-build-info.json` содержит версию и `platform: iphoneos`. Скрипт
   проверяет структуру Payload, Info.plist и Mach-O исполняемый файл.

Если job красный, откройте его лог: такой запуск не считается успешной сборкой.
В текущей среде сборка на macOS ещё не запускалась: IPA здесь не создан.
Подключение GitHub в чате позволит продолжить сборку и исправлять ошибки CI
без ручной передачи логов. До успешного запуска установка остаётся непроверенной.

## 2. Установить AltStore Classic на iPhone

Используйте официальный AltStore Classic: https://altstore.io/ .

1. На Windows установите iTunes и iCloud из источников Apple, указанных
   в официальной инструкции AltStore (ссылка ниже).
2. Установите AltServer для Windows, запустите его. Подключите разблокированный
   iPhone кабелем USB и подтвердите доверие компьютеру.
3. В iTunes войдите в свой Apple ID и включите синхронизацию iPhone по Wi-Fi.
4. В меню AltServer у часов Windows выберите Install AltStore → свой iPhone.
   Apple ID вводите только в AltServer на своём ПК; не передавайте пароль в чат.
5. На iPhone подтвердите доверие своей учётной записи в Настройки → Основные →
   VPN и управление устройством. Названия пунктов могут различаться.
6. На iOS 16+ включите Настройки → Конфиденциальность и безопасность →
   Режим разработчика и выполните указанные системой действия.

Официальная пошаговая инструкция:
https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows

## 3. Подписать и установить игру

1. Сохраните полученный IPA в приложении «Файлы» на iPhone.
2. Запустите AltServer на ПК, подключите iPhone; откройте AltStore на iPhone.
3. В My Apps нажмите «+», выберите `DurakNearby-ios-unsigned.ipa` и дождитесь
   подписания и установки. Если AltStore запросит Apple ID, используйте свою
   учётную запись на устройстве. Ошибки подписи нужно разрешить до запуска.
4. Откройте «Дурак рядом». Режим с ботом должен работать без разрешения Bluetooth.
5. Для игры вдвоём разрешите Bluetooth. На Android и iPhone используйте одну
   актуальную версию. Ведущий создаёт стол, гость находит его и вводит код.

При обычной бесплатной подписи приложения требуют обновления каждые 7 дней;
в AltStore есть Refresh All. Держите AltServer доступным для обновления.
Действует ограничение на число приложений, установленных таким способом.
Подробности: https://faq.altstore.io/altstore-classic/your-altstore

Интернет/синхронизация требуются для установки и обновления подписи, а не для
самой партии. Проверку Bluetooth проводите, отключив Wi-Fi и мобильные данные
уже после установки приложения.

## Если есть Mac

Можно обойти облачную сборку: выполните `bash tool/ios_check.sh`, затем используйте
полученный IPA с локальной подписью. Или откройте `ios/Runner.xcworkspace` в Xcode,
укажите свою Team в Signing & Capabilities и запустите приложение на подключённом
iPhone. Для TestFlight нужны Apple Developer Program и публикация сборки.
Официально: https://docs.flutter.dev/deployment/ios
